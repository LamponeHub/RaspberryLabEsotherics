## 🔧 Решение проблем

### Ошибка: "Ошибка подключения к платёжному шлюзу"

**Причина:** cURL не установлен или заблокирован

**Решение:**
1. Проверьте что cURL включён в PHP
2. Обратитесь в техподдержку хостинга:
   - "Включён ли cURL в PHP?"
   - "Разрешены ли исходящие HTTPS запросы?"

### Ошибка: "Ошибка создания платежа"

**Причина:** Неправильные credentials ЮKassa

**Решение:**
1. Проверьте Shop ID и Secret Key в `create-payment.php`
2. Убедитесь что магазин активен в личном кабинете ЮKassa
3. Проверьте что магазин не в тестовом режиме (если хотите принимать реальные платежи)

### Ошибка: "Некорректный ответ от платёжного шлюза"

**Причина:** Проблема с форматом запроса

**Решение:**
1. Проверьте логи PHP
2. Убедитесь что версия PHP >= 7.0
3. Проверьте что JSON правильно кодируется

### Платёж создаётся, но не проходит

**Причина:** Магазин в тестовом режиме

**Решение:**
1. Войдите в личный кабинет ЮKassa
2. Перейдите в "Настройки" → "Настройки магазина"
3. Отключите тестовый режим
4. Примите оферту (если ещё не приняли)

## 📊 Уведомления о платежах

### Настройка вебхуков в ЮKassa

1. Войдите в личный кабинет ЮKassa
2. Перейдите в "Настройки" → "Настройки магазина"
3. Найдите раздел "HTTP-уведомления"
4. Добавьте URL:
```
https://laboratoriolampone.com.ru/api/payment-webhook.php
```

### Создание webhook обработчика (опционально)

Создайте файл `public/api/payment-webhook.php`:

```php
<?php
// Получаем данные от ЮKassa
$input = json_decode(file_get_contents('php://input'), true);

// Проверяем что это уведомление о успешном платеже
if (isset($input['event']) && $input['event'] === 'payment.succeeded') {
    $payment = $input['object'];
    
    // Отправляем email владельцу
    $to = 'reception@laboratoriolampone.com.ru';
    $subject = 'Новый платёж получен';
    $message = "Получен платёж:\n\n";
    $message .= "ID: " . $payment['id'] . "\n";
    $message .= "Сумма: " . $payment['amount']['value'] . " " . $payment['amount']['currency'] . "\n";
    $message .= "Статус: " . $payment['status'] . "\n";
    $message .= "Описание: " . $payment['description'] . "\n";
    
    mail($to, $subject, $message);
}

http_response_code(200);
echo json_encode(['success' => true]);
?>
```
