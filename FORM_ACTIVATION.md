# Активация формы обратной связи

## 📧 Настройка FormSubmit.co

Форма на сайте настроена на отправку заявок на **reception@laboratoriolampone.com.ru** через сервис FormSubmit.co.

### ⚠️ ВАЖНО: Первая активация

При **первой отправке формы** FormSubmit.co пришлёт письмо-подтверждение на адрес **reception@laboratoriolampone.com.ru**.

#### Шаги активации:

1. **Отправьте тестовую заявку** с сайта:
   - Откройте сайт в браузере
   - Заполните форму заявки
   - Нажмите "Отправить запрос"

2. **Проверьте почту** reception@laboratoriolampone.com.ru:
   - Найдите письмо от FormSubmit.co
   - Тема письма: "Confirm your email"
   - Если письма нет в "Входящих", проверьте папку "Спам"

3. **Подтвердите email**:
   - Откройте письмо
   - Нажмите на кнопку "Confirm your email" или перейдите по ссылке
   - Вы увидите страницу подтверждения

4. **Готово!** Теперь все заявки с сайта будут приходить на почту.

## 🧪 Тестирование

### Проверка работы формы:

1. Откройте сайт в браузере
2. Заполните форму тестовыми данными:
   - Имя: Тестовый Пользователь
   - Email: test@example.com
   - Цель: Тестирование формы
   - Бюджет: 5 000 ₽
   - ✅ Согласие на конфиденциальность
3. Нажмите "Отправить запрос"
4. Проверьте почту reception@laboratoriolampone.com.ru
5. Убедитесь, что письмо пришло

### Если письмо не приходит:

1. **Проверьте папку "Спам"** — письма от FormSubmit.co могут попасть туда
2. **Добавьте в белый список:**
   - `noreply@formsubmit.co`
   - `support@formsubmit.co`
3. **Проверьте настройки почтового сервера:**
   - Убедитесь, что нет блокировки внешних форм
   - Проверьте SPF/DKIM записи
4. **Повторите активацию:**
   - Отправьте форму ещё раз
   - Найдите письмо подтверждения
   - Кликните по ссылке активации

## 📈 Аналитика

### Google Analytics

После успешной отправки формы отправляется событие:
```javascript
gtag('event', 'form_submit', {
  event_category: 'Заявка',
  event_label: '5000' // выбранный бюджет
});
```

**Где посмотреть:**
- Google Analytics → Отчёты → Взаимодействие → События
- Ищите событие `form_submit`

### Яндекс.Метрика

После успешной отправки формы отправляется цель:
```javascript
ym(12345678, 'reachGoal', 'form_submit');
```

**Где настроить:**
1. Яндекс.Метрика → Настройки → Цели
2. Добавьте цель с идентификатором `form_submit`
3. Тип цели: JavaScript-событие

**Где посмотреть:**
- Яндекс.Метрика → Отчёты → Источники → Цели
